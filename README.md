## Recommended free deployment
1. Create a GitHub repository and push this folder.
2. Create an Azure Static Web App using the Free plan.
3. Connect the GitHub repository for automatic deployment.
4. Configure Azure Static Web Apps managed authentication (GitHub or Microsoft) for production login.
5. Replace the mailto contact form with Azure Functions or another form backend if server-side enquiry capture is required.

The included login is deliberately a demo UI; it does not store credentials.
