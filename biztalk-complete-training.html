Recommended Practical Labs

Lab 1: Create XML and flat-file schemas and validate sample messages.

Lab 2: Build maps using functoids, custom XSLT and transformation testing.

Lab 3: Build a receive pipeline and send pipeline for XML/flat-file processing.

Lab 4: Build an orchestration with Receive, Transform, Decide, Send and exception handling.

Lab 5: Configure Receive Locations, Send Ports, filters, subscriptions and bindings.

Lab 6: Implement correlation and a long-running business workflow.

Lab 7: Troubleshoot suspended messages, routing failures and failed instances.

Lab 8: Package and deploy a BizTalk application using MSI and environment bindings.

Lab 9: Design a hybrid BizTalk + Azure Service Bus / Logic Apps integration.

Lab 10: Produce a BizTalk-to-Azure Integration Services modernisation roadmap.

BEGINNER

MID-LEVEL

BizTalk Professional

Advanced orchestration, correlation, BRE, BAM, routing, error handling, B2B, administration and troubleshooting.

SENIOR

BizTalk Architect & Modernisation

HA/DR, security, performance, governance, design patterns, hybrid Azure integration and BizTalk-to-Azure migration.
